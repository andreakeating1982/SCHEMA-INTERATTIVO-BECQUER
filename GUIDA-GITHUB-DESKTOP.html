Caricare il progetto dello schema su GitHub
SCHEMA INTERATTIVO
6 passaggi • 5 minuti • Gratuito

Passo 1 — Scarica e installa GitHub Desktop

1
Scarica GitHub Desktop
Vai al sito ufficiale e scarica il programma
  • Apri il browser e vai su desktop.github.com/download
  • Clicca sul pulsante "Download for Windows" (o Mac, se usi quello)
  • Apri il file scaricato e segui l'installazione guidata — è come installare qualsiasi programma, basta cliccare "Avanti" fino alla fine
💡 Consiglio: Se usi Windows, scegli la versione a 64 bit (è quella consigliata). Se usi Mac, il sito lo riconosce automaticamente.
2
Apri GitHub Desktop e accedi
Collega il programma al tuo account GitHub
  • Apri GitHub Desktop (lo trovi nel menu Start o nelle Applicazioni)
  • Alla prima apertura, clicca su "Sign in to GitHub.com"
  • Si aprirà il browser — fai il login con il tuo account GitHub
  • Il browser ti chiederà di autorizzare GitHub Desktop: clicca "Continue"
  • Torna al programma — ora sei collegato! ✅
💡 Consiglio: Se non hai ancora un account GitHub, crealo prima su github.com (gratis, 2 minuti). Poi riparti da qui.

Passo 2 — Clona il repository

3
Clona schema-interattivo sul tuo computer
Scarica una copia del repository vuoto sul PC

Ora devi clonare (scaricare) il repository schema-interattivo che hai creato su GitHub:

  • In GitHub Desktop, clicca su "File" → "Clone repository"
  • Nella finestra che si apre, clicca sulla scheda "GitHub.com"
  • Cerca nella lista il repository "andreakeating1982/schema-interattivo-sorgente" e selezionalo
  • Nella sezione "Local Path" scegli dove salvarlo (es. Desktop)
  • Clicca il pulsante blu "Clone"
  • Dopo qualche secondo, il repository è sul tuo computer ✅
⚠️ Attenzione: Se non vedi il repository nella lista, significa che non è stato creato correttamente su GitHub. Torna su GitHub.com, verifica che il repository schema-interattivo esista e sia pubblico. Se non lo vedi, crealo (Passo 1 della guida Render).
4
Apri la cartella del progetto
Accedi alla cartella appena creata
  • Sempre in GitHub Desktop, clicca con il tasto destro sul nome del repository in alto
  • Oppure clicca su "Repository" → "Show in Explorer" (Windows) o "Show in Finder" (Mac)
  • Si apre la cartella del progetto sul tuo computer
  • È vuota (o quasi) — perché il repository su GitHub è stato appena creato
💡 Consiglio: Tieni aperte entrambe le finestre: GitHub Desktop e la cartella del progetto. Ti serviranno per il prossimo passo.

Passo 3 — Copia i file dello schema

5
Copia tutti i file nella cartella del progetto
Il passaggio più importante — così carichi TUTTO su GitHub

Ecco come caricare tutti i file dello schema in una volta sola, senza il limite dei 100 file:

📁
1. Apri la cartella
La cartella "schema-interattivo" che hai appena clonato
🗑️
2. Svuotala
Seleziona tutto (Ctrl+A / Cmd+A) e cancella
📦
3. Estrai lo ZIP
Apri il pacchetto ZIP del progetto che ti ho preparato
📋
4. Copia tutto
Seleziona e copia TUTTI i file dello ZIP nella cartella
⚠️ Attenzione: Quando estrai lo ZIP, potresti trovare una cartella dentro un'altra cartella. Assicurati di copiare il contenuto della cartella interna, non la cartella stessa. Devono esserci cartelle come client/, server/, deploy/, Dockerfile, ecc.
💡 Consiglio: Il modo più semplice: apri lo ZIP, seleziona TUTTO (Ctrl+A), copia (Ctrl+C), vai nella cartella del progetto, incolla (Ctrl+V). Fatto! ✅

Passo 4 — Carica su GitHub

6
Commit e Push — il momento magico ✨
Carica tutti i file su GitHub in un colpo solo

Ora torna su GitHub Desktop — vedrai la magia! Il programma ha già rilevato tutti i file che hai copiato nella cartella.

  • Guarda GitHub Desktop: vedrai centinaia di file elencati nel pannello di sinistra, tutti con il segno verde ➕
  • In basso, dove c'è scritto "Summary (required)", scrivi:
    Primo caricamento
  • Lascia vuoto il campo "Description"
  • Clicca il pulsante blu "Commit to main"
⚠️ Attenzione: Se il pulsante blu è disabilitato, significa che non hai ancora incollato i file nella cartella. Torna al Passo 5 e ricontrolla.
7
Push — spedisci su GitHub
Carica i file su Internet

Dopo aver cliccato "Commit to main", vedrai comparire un nuovo pulsante in alto:

  • Clicca su "Push origin" (è una freccia verso l'alto, di solito sulla barra in alto)
  • GitHub Desktop inizierà a caricare tutti i file su internet
  • Vedrai una barra di progresso... e dopo qualche secondo: fatto! ✅

🎉 File caricati con successo!

Ora torna su github.com/andreakeating1982/schema-interattivo-sorgente

e vedrai TUTTI i file del progetto online! 🚀

Passo 5 — Verifica e torna alla guida Render

✅ Verifica di aver fatto tutto bene

Apri il browser e vai su github.com/andreakeating1982/schema-interattivo-sorgente

Se vedi i file del progetto (cartelle client, server, deploy, file Dockerfile, ecc.) — sei a posto! ✅
