1 Preparazione — Account e Repository

1
Crea un account GitHub (gratuito)
Se non ce l'hai già
  • Apri il browser e vai su github.com
  • Clicca su "Sign up" (in alto a destra)
  • Inserisci email, password e nome utente
  • Conferma l'email che ricevi
  • Seleziona il piano gratuito (Free)
💡 Consiglio: Usa un nome utente semplice come "andreakeating1982" (quello che hai già). Ti servirà per tutti i passaggi successivi.
⚠️ Se hai già un account: Vai su github.com e fai il login. Passa direttamente al Passo 2.
2
Crea il repository schema-interattivo
Il "contenitore" del progetto su GitHub
  • Dopo il login, clicca sul pulsante "+" (in alto a destra) → "New repository"
  • Oppure vai direttamente su github.com/new
  • Nel campo "Repository name" scrivi: schema-interattivo
  • Lascia selezionato "Public" (visibile a tutti, ma va bene così)
  • NON spuntare nessuna casella (no README, no .gitignore, no license)
  • Clicca il pulsante verde "Create repository"
💡 Attenzione: Il nome deve essere esattamente "schema-interattivo" (tutto minuscolo, con il trattino). Se usi un nome diverso, il deploy su Render non funzionerà.

2 Caricare i file con GitHub Desktop

3
Scarica e installa GitHub Desktop
Il programma che carica i file su GitHub
  • Apri il browser e vai su desktop.github.com/download
  • Clicca su "Download for Windows" (o "for macOS" se usi Mac)
  • Apri il file scaricato e installalo (clicca "Avanti" fino alla fine)
💡 Consiglio: Se usi Windows, scegli la versione a 64 bit (quella consigliata). Se usi Mac, il sito lo riconosce automaticamente.
4
Accedi a GitHub Desktop
Collega il programma al tuo account
  • Apri GitHub Desktop (lo trovi nel menu Start / Applicazioni)
  • Alla prima apertura, clicca su "Sign in to GitHub.com"
  • Si aprirà il browser — fai il login con il tuo account GitHub
  • Il browser ti chiederà di autorizzare GitHub Desktop: clicca "Continue"
  • Torna al programma — ora sei collegato! ✅
5
Clona il repository sul computer
Scarica il "contenitore vuoto" sul PC
  • In GitHub Desktop, clicca su "File" → "Clone repository"
  • Nella finestra che si apre, clicca sulla scheda "GitHub.com"
  • Cerca nella lista il repository "andreakeating1982/schema-interattivo-sorgente" e selezionalo
  • In "Local Path" scegli dove salvarlo (es. Desktop)
  • Clicca il pulsante blu "Clone"
  • Dopo qualche secondo, il repository è sul tuo computer ✅
⚠️ Se non vedi il repository nella lista: Torna su GitHub.com e verifica che il repository "schema-interattivo" esista e sia pubblico. Se non c'è, ricrealo (Passo 2).
6
Copia i file del progetto
Il passaggio più importante!

Ora devi copiare i file dello schema nella cartella appena creata. Segui questi passaggi nell'ordine esatto:

📂
Apri la cartella
In GitHub Desktop: Repository → Show in Explorer
🗑️
Cancella tutto
Seleziona SOLO i file visibili, NON le cartelle nascoste
📦
Estrai lo ZIP
Apri il pacchetto del progetto che ti ho preparato
📋
Copia e incolla
Seleziona TUTTO dalla cartella estratta, copia, incolla
⚠️ ATTENZIONE — Errore comune: Quando estrai lo ZIP, i file potrebbero essere dentro una cartella annidata. Devi copiare il CONTENUTO della cartella interna (client/, server/, Dockerfile, ecc.), non la cartella esterna.
💡 Il modo più semplice: Apri lo ZIP → apri la cartella interna → seleziona TUTTO (Ctrl+A) → copia (Ctrl+C) → vai nella cartella del progetto (Show in Explorer) → incolla (Ctrl+V). Fatto! ✅
7
Commit e Push — carica su GitHub
Il momento in cui i file diventano online

Dopo aver copiato i file, torna su GitHub Desktop — vedrai l'elenco di tutti i file pronti per essere caricati:

  • Nel campo in basso "Summary (required)", scrivi: Primo caricamento
  • Lascia vuoto il campo "Description"
  • Clicca il pulsante blu "Commit to main"
  • Poi clicca su "Push origin" (frecetta verso l'alto sulla barra in alto)
  • GitHub Desktop caricherà tutti i file su internet...

🎉 File caricati con successo!

Vai su github.com/andreakeating1982/schema-interattivo-sorgente e vedrai tutti i file del progetto online! 🚀

3 Pubblicare online con Render

8
Crea un account Render (gratuito)
La piattaforma che ospiterà lo schema
  • Vai su dashboard.render.com
  • Clicca su "Sign Up" (in alto a destra)
  • Scegli "Sign up with GitHub" — è il modo più veloce
  • Autorizza Render a connettersi al tuo GitHub
  • Completa la registrazione e conferma l'email
💡 Consiglio: Usa "Sign up with GitHub" così Render vedrà automaticamente i tuoi repository. Non dovrai cercarli a mano.
9
Deploy con Blueprint — tutto automatico
Render crea database e server in un colpo solo
  • Appena entrato su Render, clicca su "New +" (in alto a destra)
  • Scegli "Blueprint" dal menu a tendina
  • Seleziona "Connect repository" e cerca "schema-interattivo"
  • Connetti il repository e clicca "Apply" (in fondo alla pagina)
  • Render farà tutto da solo:
    ✅ Creerà un database PostgreSQL
    ✅ Creerà il web service con Docker
    ✅ Avvierà l'app automaticamente
  • Attendi circa 5 minuti...
💡 Cosa succede dopo "Apply"? Render apre una pagina "Blueprints" che mostra due righe: una per il database (schema-db) e una per il web service (schema-interattivo). Dopo qualche minuto, entrambi diventano verdi ✅
⚠️ Se il web service è rosso (Failed): Clicca sul nome del servizio, vai su "Logs" e guarda l'ultimo errore. Poi mandami lo screenshot e ti aiuto a risolvere!

4 Collegare lo schema al blog Blogger

Ora che lo schema è online su Render, puoi incorporarlo nel tuo blog. Basta un semplice codice da incollare nel tuo post o pagina.

10
Inserisci l'iframe nel blog
Copia, incolla e pubblica — 2 minuti

Copia questo codice esattamente com'è:

<div style="text-align: center; margin: 20px 0;">
<iframe
src="https://schema-interattivo.onrender.com/"
style="width: 100%; max-width: 480px; height: 700px;
border: none; border-radius: 12px;
box-shadow: 0 4px 20px rgba(0,0,0,0.1);"
allowfullscreen>
</iframe>
</div>

Poi segui questi passaggi su Blogger:

  • Vai su blogger.com e accedi
  • Clicca su "Nuovo post" (o modifica una pagina esistente)
  • Nell'editor, clicca su "HTML" (in alto a sinistra, accanto a "Componi")
  • Incolla il codice qui sopra dove vuoi che appaia lo schema
  • Clicca su "Componi" per vedere l'anteprima
  • Clicca "Pubblica" in alto a destra ✅
💡 Se lo schema appare tagliato: Cambia height: 700px in height: 800px nel codice e riprova.
💡 Pagina dedicata: Invece di un post, puoi creare una "Pagina" nel tuo blog (dal menu Layout → Pagine) chiamata "Schema Interattivo" e mettere l'iframe lì. È più ordinato!
